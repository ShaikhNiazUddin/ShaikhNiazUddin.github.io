PUBLISH WITH GITHUB DESKTOP
1. Sign into GitHub Desktop with your own GitHub account.
2. File > New repository. Name it YOUR-USERNAME.github.io, replacing YOUR-USERNAME with your exact GitHub username.
3. Open the new repository folder in File Explorer.
4. Copy ALL extracted website files and folders into that repository folder.
   index.html must be directly inside the repository, not inside an extra folder.
5. In GitHub Desktop, enter a summary such as Publish portfolio, then Commit to main.
6. Click Publish repository. Uncheck Keep this code private to make it public, then publish.
7. On GitHub, open that repository > Settings > Pages.
8. Choose Deploy from a branch, main, / (root), then Save.
9. Wait for deployment. The Pages settings will display your live website link.
